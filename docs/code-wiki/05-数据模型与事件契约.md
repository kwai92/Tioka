- 迁移目录：[tioka-server/src/main/resources/db/migration](file:///f:/AI时代/Tioka/tioka-server/src/main/resources/db/migration)（同时镜像在 [docs/contracts/db](file:///f:/AI时代/Tioka/docs/contracts/db)）

## 2. 事件与消息（MQ）

### 2.1 信封

统一信封结构：`docs/contracts/events/mq-envelope-v1.json`，字段含 `eventId`、`event`、`workspaceId`、`traceId`、`runAs`、`payload`。**不含 `tenantId`**（ADR-029）。开发/测试环境由 `EnvelopeSchemaValidator` 校验。

### 2.2 传输与主题

- 传输：`tioka.messaging.mode` = `rocketmq` | `in-memory`（IT 默认 in-memory）
- 编排主题常量：`OrchestrationMqTopics`（TOPIC=`tioka-orch`；TAG：`event.received` / `run.claimed` / `run.completed` / `attention.opened` / `attention.answered` / `trigger.fired`）
- 各模块 `*-api` 内定义自己的 MQ Topic 常量（禁止 biz 内硬编码字符串）
