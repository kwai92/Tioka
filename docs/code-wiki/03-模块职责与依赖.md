> 每个业务模块统一拆为 `-api`（契约/SPI/MQ 常量，可被跨模块依赖）与 `-biz`（实现，仅被 `tioka-server` 聚合）。

## 2. 逐模块职责明细

### 2.1 system（Foundation）
身份与安全基座。两层权限：功能权限（`@RequirePermission` + `PermissionAspect`）与资源级 ACL（`DefaultResourceGuard`：`VIEW < USE < EDIT < OWNER`）。令牌 Redis 生命周期（access/refresh + 家族吊销）。OIDC 授权码 + PKCE 登录与身份联邦（组同步、角色映射）、SCIM 增量同步、API Key（服务账号权限 ∩ scopes）。审计写入 + 哈希链封印。配额三维度（workspace/user/agent × tokens_month/concurrent_turns）。密钥 AES-GCM 存储（兼容旧 ECB）。出网守卫与出网台账。

### 2.2 infra
全系统异步通信底座。事务 Outbox（`sys_outbox`）+ Relay（Redis 锁选主、按 `msg_key` 顺序）+ 幂等消费（`sys_consumed`）+ 死信（`sys_dead_letter`，OPEN/REPLAYED/DISCARDED）+ 通知门面（`ntf_delivery` 去重）+ 插件宿主（默认关闭）。传输可切换 RocketMQ / 进程内 `InMemoryMessageTransport`（`tioka.messaging.mode`）。

### 2.3 runtime
六边形架构执行内核。纯领域 `AgentLoop` + `LoopPorts`（ModelPort/ToolPort/ItemSink/SignalPort）。Turn 生命周期管理与租约；工具网关（授权管线 1–7 步）+ 治理管线（9–12.5 步：Cedar 策略、自治、爆炸半径、去向许可）；审批挂起/恢复；子 Agent 委派；撤销补偿与熔断；SSE 流式；AG-UI 兼容网关。

### 2.4 orchestration
事件驱动编排。`ingest`（hops 熔断 + 幂等去重 + 按 eventType 找规则）→ `decide`（规则版本选择 + CEL 求值 + 灰度回落 + 授权书复验）→ `assign`（工单 + Mandate + Run，按 serial/merge/parallel 并发模式）→ `dispatch`（派工到 Agent/Flow）→ 回执（notice/ask/later/emit）。规则版本 DRAFT/CANARY/STABLE/RETIRED + 灰度；规则连续失败自动暂停；定时轮询器；Turn 完成观察者回写 Run 状态。

### 2.5 chat
对话会话容器。异步发送（`POST messages` 立即 202，由 runtime 异步执行）；会话绑定 runtime thread，消息从 `RuntimeApi` item 投影；卡片（续答/审批）与记忆存储；会话级成本归集；事件驱动更新会话预览。

### 2.6 knowledge
知识全生命周期。五阶段异步入库流水线 PARSE→CHUNK→EMBED→SWAP（失败重试，SWAP 原子切换版本）；结构化父子块切分（父块存上下文、子块向量化）；混合检索（向量 + 全文两路召回 → RRF(k=60) 融合 → rerank 重排，失败降级 RRF）；文档级 ACL 下推；内容哈希去重；Wiki 页面；数据源绑定同步；`KbToolProvider` 暴露 `kb.*` 工具。

### 2.7 flow
真 DAG 调度器。边状态 PENDING/LIVE/DEAD，Branch 未选路径 SKIPPED 传播；有界并行（固定 4 线程池）；wave 并行执行。DSL（YAML/JSON）编解码与多阶段发布校验（结构 → 类型/表达式 → 引用/权限 → 子流程循环 → 限制 → 质量）；端口类型兼容；凭证安全（禁硬编码密钥，用 secretRef）；Flow-as-Tool 发布 + 授予前置检查；Webhook HMAC 验签。

### 2.8 connector
第三方集成桥梁。IM 渠道适配器（飞书 OpenAPI/Webhook、钉钉 Webhook、企微 Webhook）+ IM outbox；飞书文档同步（本地镜像 + OpenAPI 拉取/推送）；飞书/钉钉卡片构建；连接器 SDK（实例注册、令牌桶限流、重试、游标、凭证绑定）；OAuth HMAC state 校验（防 CSRF/开放重定向）；IM 去向许可（PASS/REDACTED/DENY）。

### 2.9 model
模型 Hub 与网关。目录（Provider/Alias/Binding/Plan）CRUD + 版本化发布（snapshotHash）；网关容错链：同 binding 重试（指数退避）→ 冷却（滑动窗口失败计数）→ 令牌桶限流（RPM/TPM，Lua 脚本，TPM 预扣+补差）→ 预算守护 → 故障接力（fallbackBinding/fallbackChain）；路由计划（启发式/LLM/HTTP 决策器）；成本汇总/趋势/会话时间线；路由遥测与胜任度记录。

### 2.10 agent
Agent 资产全生命周期。`AgentSpec`（schemaVersion=1）配置快照（Profile/Instructions/ModelPolicy/ToolSet/SkillRef/KnowledgeBinding/SandboxPolicy/ApprovalSettings/Limits/Charter/…）。草稿（revision 乐观锁）→ 发布（不可变版本，CanonicalJson SHA-256）→ 回滚；可插拔 `PublishCheck` 校验链（`@Order`）；授权书 Charter 类型化校验 + Cedar 编译；快照 Caffeine 缓存 + 发布事件失效。

### 2.11 mcp
MCP 管理与调用。服务器注册 + `tools/list` JSON-RPC 工具发现（兼容 `application/json` 与 SSE `data:`）+ 全量替换（保留已配置 risk）；工具风险四态 READ/WRITE/DESTRUCTIVE/EXTERNAL_SEND（默认 WRITE，`readOnlyHint=true` 默认 READ）+ 可逆性覆盖；健康检查（连续 3 次失败开熔断）；`McpToolProvider` 实现 Runtime `ToolProvider` SPI 暴露工具。

### 2.12 skill
Skill 资产。ZIP 包导入（`manifest.json` + `SKILL.md`）→ 发布；`SkillQueryApi` 查询；签名策略（`tioka.skill.force-signature`）。M1 阶段无独立版本表（`skillVersionId` == `skill_package.id`，AST-05 补表）。

### 2.13 ontology
业务本体。领域包（DomainPack）为插件单元：Schema 登记/校验/证据检查；文档（去重+解析+落库，PDF/DOCX/图片 OCR）；模型定义草稿/发布/回滚/diff；实例草稿（revision 乐观锁）；折叠引擎（`FoldingEngine`，input_hash 幂等，Redis 锁按 storeKey 串行）；读模型行级 ACL（无权限返回 empty，不泄露存在性）。**无 REST 控制器**，经 API 被调用。

### 2.14 governance
策略与信任控制中枢。Cedar forbid-only 两遍求值（DRYRUN/ENFORCE，失败安全降级）；统一配置版本框架（草稿/发布/回滚/导出 + 投影缓存 + 跨实例刷新总线）；授权书生命周期状态机（ACTIVE/SUSPENDED/HANDOVER，CAS 转移）；自治等级 L0–L4（判定表 + 自动降级 + 撤销熔断）；数据标签下沉防护。**无 REST 控制器**。

### 2.15 eval
质量度量。批次评测（多评估器、trials 1–10、密封集隔离、聚类区间估计）；数据集五层分级（SMOKE/DEV/SEALED/REGRESSION/SPECIAL）+ 材料单元跨层校验；反馈（USER/UNDO/REVIEW 多源）；知识召回评测（Recall@5/MRR 基线）；轨迹导出（OTel GenAI 语义）。工具调用在评测中一律进审批后立即取消（外部零变更）。

### 2.16 非业务模块
- `tioka-framework`：安全上下文、错误码、ULID、CanonicalJson、持久基类（BaseDO/AppendOnlyDO/ImmutableSnapshotDO/MutableRecordDO/WorkspaceAwareDO）、MyBatis 拦截器（ScopeLineHandler/TiokaMetaObjectHandler）、Principal 模型、TraceContext、消息内核（EventEnvelope/EventPublisher/IdempotentConsumer）、AES-GCM 凭证加密。
- `tioka-server`：Spring Boot 启动层、Flyway 迁移、ops 门面、资产目录、MCP 出站服务、全局异常处理。
- `tioka-testkit`：测试工具（`FakeErp` 等 Fake SPI 实现、可注入失败）。
- `tioka-pack-lease`：租赁领域包（DomainPack SPI 纯计算，V01–V16 校验器 + 折叠引擎 + CEL 函数）。

## 4. 禁止项（架构红线）

- 任何 `*-biz` 依赖其他 `*-biz`
- `runtime-biz` 直接依赖 `connector`（飞书/MCP SDK 放 connector；Runtime 只看 Tool SPI）
- `chat-biz` ↔ `flow-biz` 互相依赖（经 runtime / orch / MQ）
- 在 biz 内硬编码 MQ Topic 字符串（必须用 `-api` 模块常量）
- Agent 散落主模型字段绕过 `model-api` RoutingPlan
- 事件正文决定路由/权限（正文只作数据，路由/鉴权由字段与策略决定）
