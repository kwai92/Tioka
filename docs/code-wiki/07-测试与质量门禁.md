# 07 · 测试与质量门禁

## 1. 测试分层

| 层级 | 位置 | 说明 |
|---|---|---|
| 单元测试 | 各模块 `src/test`（`*Test.java`） | 默认 `mvn verify` 执行；随机顺序，排除 `@Tag("gate")`，排除 `**/*IT.java` |
| 集成测试 | `**/*IT.java` | 默认**不**执行；由 `-Pgate` 或 failsafe 触发 |
| 门禁测试 | [gate 包](file:///f:/AI时代/Tioka/tioka-server/src/test/java/com/tioka/server/gate)（`*GateIT.java`，`@Tag("gate")`） | G0–G3 端到端；`-Pgate` 执行，Testcontainers 起依赖 |
| 前端测试 | `tioka-ui`（Vitest + happy-dom） | `npm test` |
| 架构测试 | ArchUnit | 校验模块依赖基线与分层规则 |

Surefire/Failsafe 统一：`-Dnet.bytebuddy.experimental=true -Duser.timezone=UTC`，`runOrder=random`（见 [pom.xml](file:///f:/AI时代/Tioka/pom.xml)）。

## 2. Maven Profile

| Profile | 作用 |
|---|---|
| 默认（无 profile） | 单元测试；排除 gate 与 `*IT` |
| `-Pgate` | 只跑 gate 用例（`groups=gate`、`includes=**/*IT.java`、`-Dgate=true`）；同时 `skipITs=true` 让 failsafe 不双跑 |

```bash
# 单元/常规
mvn -B verify

# 门禁（含 Testcontainers）
mvn -B verify -Pgate

# 仅跑单个门禁端到端（真实模型）
mvn -B -pl tioka-server -am verify -Pgate \
  -Dtest=G1EndToEndGateIT -Dit.test=G1EndToEndGateIT -Dtioka.real-model=true
```

## 4. 静态门禁与守护

| 前端 lint/type/build | `npm run lint/typecheck/build` | `tioka-ui` |

## 5. CI 流水线（.github/workflows）

### ci.yml（push: main/master/develop/feature/**/feat/**，或 PR）

三个并行 Job：

| Job | 内容 |
|---|---|
| backend | JDK 17 + Maven 缓存 → `mvn -B verify` |
| gate | JDK 17（`-Xmx3g`）→ 预拉 Keycloak/RocketMQ/Mailpit 镜像 → `mvn -B verify -Pgate`（`TESTCONTAINERS_RYUK_DISABLED=true`） |
| frontend | Node 20 → `npm ci` → `lint` → `typecheck` → `test` → `build` |

### nightly-real-model.yml（每日 UTC 18:00 / 手动）

- 检查 secrets（`TIOKA_REAL_MODEL_BASE_URL` / `API_KEY` / `MODEL`），缺失则跳过
- 预拉 Keycloak 镜像
- 仅跑 `G1EndToEndGateIT`，`-Dtioka.real-model=true`
- 非必需检查

## 6. 验收脚本对照

| 脚本 | 覆盖 |
|---|---|
| `accept.sh` | SLICE 级：Maven test + UI build + 审计勾选 + G1–G7 用例存在性（不等于商业门禁） |
| `accept-fidelity.sh` | 保真静态检查：MCP/飞书/OIDC/pgvector/Knowledge/Vue Flow 等代码与配置面存在 |
| `accept-poc-exit.sh` | 商业 PoC Gate / W1 Exit：工程门禁 + 产品签字页 |

## 7. 测试支撑（tioka-testkit 与 stub）

- `FakeErp`：内存 ERP（`TransactionalTool` SPI），可注入数据漂移与补偿失败，验证容错路径。
- 服务器端 stub：`LlmStubServer`（含 SSE）、`McpStubServer`、`FeishuStubServer`、`MailpitContainer`、`ChineseEmbeddingContainer`、`GateCluster`（多实例 gate）。
- 依赖容器：Testcontainers（PostgreSQL/Redis/Keycloak/RocketMQ/Mailpit）。

## 8. 本地快速自测

```bash
mvn -q -DskipTests compile        # 编译
mvn -B verify                     # 单元测试
mvn -B verify -Pgate              # 门禁（需 Docker）
cd tioka-ui; npm run lint; npm run typecheck; npm test; npm run build
```
