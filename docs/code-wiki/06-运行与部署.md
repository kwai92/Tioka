# 06 · 运行与部署

## 1. 环境要求

| 组件 | 版本 |
|---|---|
| JDK | 17（macOS 可 `export JAVA_HOME=$(/usr/libexec/java_home -v 17)`） |
| Maven | 3.9+（多模块聚合 + flatten 插件） |
| Node.js | 20（前端 `tioka-ui`） |
| Docker + Compose | 运行中间件 |
| PostgreSQL | 16 + pgvector |

## 2. 中间件（deploy/compose.yml）

```bash
docker compose -f deploy/compose.yml up -d
```

| 服务 | 镜像 | 端口 | 说明 |
|---|---|---|---|
| postgres | `pgvector/pgvector:pg16` | 5432 | 库名/用户/密码均为 `tioka`，挂载 `init-pgvector.sql`（建 vector 扩展） |
| redis | `redis:7-alpine` | 6379 | 缓存 / 令牌 / 租约 / 事件流 |
| keycloak | `quay.io/keycloak/keycloak:24.0` | 8180 | OIDC（`start-dev --import-realm`，admin/admin） |
| rocketmq-namesrv | `apache/rocketmq:5.3.1` | 9876 | 消息 NameServer |
| rocketmq-broker | `apache/rocketmq:5.3.1` | 10911 | 消息 Broker |
| jaeger | `jaegertracing/all-in-one:1.57` | 16686 / 4317 | 链路追踪 UI / OTLP gRPC |

> compose 中**不含** Tioka 应用本身与 Mail 服务（Mailpit 仅 CI gate 使用）。应用以本地进程或 [deploy/Dockerfile](file:///f:/AI时代/Tioka/deploy/Dockerfile) 运行。

## 3. 启动后端

```bash
# 编译（跳过测试）
mvn -q -DskipTests compile

# 启动（默认 profile=local，模型/MCP 走 mock）
mvn -q -pl tioka-server -am spring-boot:run
```

- 入口类：[TiokaServerApplication](file:///f:/AI时代/Tioka/tioka-server/src/main/java/com/tioka/server/TiokaServerApplication.java)
- 默认端口：`8080`（[application.yml](file:///f:/AI时代/Tioka/tioka-server/src/main/resources/application.yml) `server.port`）
- 启动时 Flyway 自动执行 `db/migration` 迁移（最高 `V227`）
- 健康检查：`GET /actuator/health`、`/actuator/info`

## 4. 启动前端

```bash
cd tioka-ui
npm install
npm run dev        # http://localhost:5173
```

- Vite 代理：`/api` → `http://localhost:8080`（SSE 关闭代理缓冲）
- SSE 端点：`GET /api/runtime/threads/{threadId}/events`（`@microsoft/fetch-event-source`，支持 `Last-Event-ID`/`after` 续传与断线退避重连）
- 构建/校验脚本：`npm run build`（`vue-tsc --noEmit && vite build`）、`npm run lint`、`npm run typecheck`、`npm test`、`npm run gen:api`

## 5. 配置与 Profile

配置文件位于 `tioka-server/src/main/resources/`：

| 文件 | 作用 |
|---|---|
| [application.yml](file:///f:/AI时代/Tioka/tioka-server/src/main/resources/application.yml) | 基础配置：数据源、Redis、Flyway、MyBatis-Plus、mock 开关、审计、消息、orch、IM、出网等 |
| [application-local.yml](file:///f:/AI时代/Tioka/tioka-server/src/main/resources/application-local.yml) | 本地（默认激活）：`embedding dim=32`、出网 OPEN、OIDC 可配、无生产密钥强制 |
| [application-prod.yml](file:///f:/AI时代/Tioka/tioka-server/src/main/resources/application-prod.yml) | 生产：`mock=false`、RocketMQ 启用、`secret.require-external-key=true` |
| [application-fidelity.yml](file:///f:/AI时代/Tioka/tioka-server/src/main/resources/application-fidelity.yml) | 保真：关闭所有 mock，强制真实外部依赖 |

> 真实 LLM：`tioka.model.mock=false`（或 `TIOKA_MODEL_MOCK=false` + `SPRING_PROFILES_ACTIVE=...fidelity/ext`），并配置 Provider `baseUrl` 与 SecretStore API Key。

### 常用开关（按需）

| 键 | 默认 | 说明 |
|---|---|---|
| `tioka.model.mock` | `true` | 模型 mock；保真置 false |
| `tioka.mcp.mock` | `true` | MCP mock |
| `tioka.messaging.mode` | `in-memory` | `rocketmq` \| `in-memory` |
| `tioka.messaging.relay-enabled` | `false` | Outbox 中继（生产开） |
| `tioka.ontology.schema.enabled` | `false` | Schema 注册表 |
| `tioka.config.version.enabled` | `false` | 配置版本框架 |
| `tioka.eval.enabled` | `false` | 评测模块 |
| `tioka.notify.enabled` | `false` | 通知渠道 |
| `tioka.plugin.enabled` | `false` | 插件宿主 |
| `tioka.secret.master-key` / `tioka.credential.master-key` | 空 | 主密钥（生产必填） |
| `tioka.observability.enabled` | `${TIOKA_OTEL_ENABLED:false}` | OTel |

### 关键环境变量（节选）

`TIOKA_DB_HOST/PORT/NAME/USER/PASSWORD`、`TIOKA_REDIS_HOST/PORT`、`TIOKA_EMBEDDING_DIM`、`TIOKA_MESSAGING_MODE`、`TIOKA_MQ_NAMESRV`、`TIOKA_SECRET_MASTER_KEY`、`TIOKA_FEISHU_APP_ID/APP_SECRET/…`、`TIOKA_OTEL_ENABLED`、`OTEL_EXPORTER_OTLP_ENDPOINT`、`TIOKA_TRACE_URL_TEMPLATE`。

## 6. 容器构建（生产）

[deploy/Dockerfile](file:///f:/AI时代/Tioka/deploy/Dockerfile)：

- 基础镜像 `eclipse-temurin:17-jre`
- 内置 OpenTelemetry Java Agent 1.33.5（自动埋点 Spring MVC/JDBC/Lettuce/HttpClient/RocketMQ）
- `JAVA_TOOL_OPTIONS="-javaagent:/app/opentelemetry-javaagent.jar -Duser.timezone=UTC"`
- `OTEL_SERVICE_NAME=tioka`、`OTEL_TRACES_EXPORTER=otlp`
- 入口：`java -jar /app/app.jar`（构建产物 `tioka-server/target/tioka-server-*.jar`）
