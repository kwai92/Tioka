# GL — Tioka 统一名词释义

> 权威领域语言与工程命名。与 ADR / 代码冲突时：以 **更新后的 ADR-029**、本表、[48-CS](48-CS-编码规约摘要.md) 为准。  
> 跨系统摘要见 [S0 §3](../systems/S0-体系总览与边界.md)。按域闭环扩展：已完成 **system**、**runtime**、**chat**、**agent/mcp/skill**、**model**、**orch/flow**、**knowledge/connector**（全域名词表齐）。

### 1.1 Runtime（ADR-016）

| 术语 | 中文 | 定义 | 禁止同义 |
| --- | --- | --- | --- |
| Thread | 执行线程/会话 | 一次 Agent 执行上下文；API/`threadId`；表 **`runtime_thread`** | 对外再叫 Session；物理旧名 `runtime_session` 已废止 |
| Turn | 轮次 | Thread 上一次异步运行单元；`TurnStatus` | — |
| Item | 条目 | Thread 内单调 `seq` 的内容/事件原子 | 对外 Part；`message` 仅作 ItemType |
| Step | 步 | 单 Turn 内模型↔工具迭代序号 | 与 Item.seq 混用 |
| ToolGateway | 工具网关 | 工具出站唯一入口 | 业务域直连工具/供应商 |
| Approval | 审批 | 按 subject 的人审挂起 | — |
| SubAgent / Child Thread | 子代理 | 子 Thread；父 Turn `WAITING_CHILD` | 另造第三套会话产品名 |
| ThreadLock | 线程锁 | 同一 Thread 互斥执行；Redis `rt:lock:{threadId}` | SessionLock（已废止类名） |

MQ tag 权威：`thread.created` / `thread.completed` / `item.appended`（旧 `session.*` / `part.*` 常量仅 Deprecated alias）。

### 1.2 Chat（ADR-022）

| 术语 | 中文 | 定义 | 禁止同义 |
| --- | --- | --- | --- |
| Conversation | 会话 | 产品侧会话壳（标题、归属、Agent 绑定）；经 `runtime_thread_id` 关联 Thread | 勿称 Runtime Thread 为 Conversation |
| Branch | 分支 | Conversation 内一条执行线 ↔ 一个 Thread（`parent`/`fork_seq`）；**未落地** | — |
| Message（产品） | 消息 | 用户可见一轮对话；存储为 Thread 上的 Item；`GET .../messages` 返回 Item 投影 | 勿落独立 `chat_message` 表（已删） |
| Part | 部件 | 展示枚举（卡片/表单等）；卡片临时 DTO 用 `CardMessage.parts` | 称 Runtime Item 为 Part |
| CardMessage | 卡片响应 | 卡片 API 临时 DTO（非持久化 Message） | 与产品 Message / Item 混称 |
| Memory（stub） | 会话 KV | 表 `chat_memory` 仅为密度/偏好 stub | 冒充 ADR-050 长期记忆 |
| MemoryItem | 长期记忆项 | ADR-050 `mem_*` | `chat_memory_item`（已废止路径） |

### 1.3 Agent / MCP / Skill（资产控制面；ADR-023 / ADR-021）

| 术语 | 中文 | 定义 | 禁止同义 |
| --- | --- | --- | --- |
| Agent | 智能体资产 | 空间内可版本化配置；表 **`agent_agent`**；API `/api/agents` | 与 Runtime SubAgent/Child Thread 混称「会话」 |
| AgentDraft | 草稿 | 可编辑 Spec；表 **`agent_draft`** | 把未发布内容当 AgentVersion |
| AgentVersion | 已发布版本 | 不可变 Spec 快照（本域 Publication）；表 **`agent_version`** | 另建独立「Publication 表」 |
| AgentSpec | 配置文档 | 类型化 JSON（model/tools/skills/…） | 散落 `mcp_grant` / sandbox 表回潮 |
| AgentSnapshot | 版本读模型 | `AgentSnapshotApi` 投影；非独立表 | 与 MCP Server Snapshot 混称 |
| McpServer | MCP 服务登记 | 表 **`mcp_server`** | 在 Agent 上填野 URL |
| McpTool | 工具目录行 | 发现缓存（现 `mcp_tool`；目标钉快照） | 称 Runtime ToolDescriptor / Skill 为 McpTool |
| McpBinding | Agent↔MCP 绑定 | Spec `tools.mcp[]`：`serverId` + allowlist；运行时信封键 **`mcp`** | **mcpGrant / mcpGrants / grantId** |
| SkillPackage | Skill 逻辑包 | 表 **`skill_package`** | 无前缀 package 指任意 zip |
| SkillVersion | Skill 不可变版本 | 目标表；**M1 过渡**：`skillVersionId` ≡ `skill_package.id` | 无版本却对外假装有 Version 且不注明 |
| SkillRef | Agent 内 Skill 引用 | Spec `skills[]`：`skillVersionId` + mode | 独立 binding 表回潮 |
| SkillInstall | 运行时装载 | Runtime 只读装到工作盘 | 向 ToolGateway 注册 Skill 伪工具 |
| FlowPublication | Flow 通道发布物 | S14；Agent `tools.flows` 引用 | 与 AgentVersion 都裸称 Publication |
| AssetListing | 市场上架 | 目标取代 `agent_marketplace`（ADR-023） | 每类资产各造 marketplace 表名（长期） |

表前缀以代码为准：`agent_*` / `mcp_*` / `skill_*`（S 文档历史 `ag_*`/`sk_*` 作废）。

## 2. 工程 / 代码名词

| 后缀 / 形态 | 含义 | 包 / 模块 |
| --- | --- | --- |
| `*DO` | 持久化实体，继承 `BaseDO` / `WorkspaceAwareDO` 等 | `infrastructure.persistence`（**禁止**再开 `dataobject`） |
| `*Mapper` | MyBatis-Plus Mapper | `infrastructure.mapper` |
| `*Repository` | 仓储；封装 Mapper，供 application 调用 | `infrastructure` |
| `*Service` | 应用服务；事务边界通常在此 | `application` |
| `*Controller` | HTTP 适配（薄） | biz 内 `api` 包 |
| `*Api` | 跨模块 Java API 契约 | `*-api` |
| `*Port` | 出站端口（本域依赖外部能力的抽象） | `*-api` |
| `*Guard` | 鉴权 / 配额等防护契约 | `*-api` |
| `*Adapter` | SPI 适配器实现侧接口 | `*-api` / spi |
| `*Hook` / `*Sink` | 扩展钩子 / 事件汇 | 按域登记，避免与 `*Api` 混用同一语义 |

分层硬约束：`application` → `Repository` → `Mapper`；`*-biz` 不依赖其他 `*-biz`。

## 3. 禁用同义词 → 权威词

| 禁用 | 权威 | 说明 |
| --- | --- | --- |
| Tenant（产品实体） | Workspace / 单企业部署 | 不做租户开通与跨租户产品 |
| `tenant_id` / `tenantId`（DO、API、新迁移） | `workspace_id` / `workspaceId` | ADR-029 第 60 条 |
| `tenant_admin` | `system_admin` | 2026-11-07 起废止旧码 |
| OIDC `tenant-role` / `tenantRole` | `system-role` / `systemRole` | 组映射到系统级角色 |
| 租户管理员（对用户话术） | 系统管理员 | UI 文案 |
| 对外 Session（Runtime） | Thread | 表/API/锁均已 Thread |
| `runtime_session` / 列 `session_id`（Runtime 子表） | `runtime_thread` / `thread_id` | V128 起 |
| `runtime_session_id`（chat） | `runtime_thread_id` | V128 起 |
| MQ `session.*` / `part.appended` | `thread.*` / `item.appended` | 旧常量 Deprecated alias |
| Conversation JSON `runtimeThreadId` | `threadId` | Chat API 只暴露 threadId |
| 称 Item 为 Part / Message 落库 | Item 投影 / CardMessage | 见 §1.2 |
| `mcpGrants` / `McpGrant` / `grantId`（Agent 工具配置） | `mcp` / `McpBinding` | Spec `tools.mcp`；表 `mcp_grant` 已删 |
| 称 Skill 为 Tool / MCP Tool | SkillPackage / SkillRef | S13 硬约束 |
| 裸 Binding（跨域） | `McpBinding` / `ModelBinding` / `ImBinding` 等 | 必须带域前缀 |
| Deployment（Model Hub 独立实体） | ModelBinding | S10 混写作废 |
| S10 文档 `mdl_*` | `model_*` | 以 `@TableName` 为准 |
| SessionFreeze / `model_session_freeze` | TurnFreeze / `model_turn_freeze` | 已迁 thread |
| `orch_attention` / 对外 claim 工人审 | `runtime_approval` + Attention 语义 | V132 目标 |
| `orch_why` / API `why` | `orch_fact` / `facts` | V132 目标 |
| `flow_tool_pub` | `flow_publication` | V129 已 RENAME；V143 重建仍待合入 |
| Flow 侧裸 Publication / FlowDefinition | FlowPublication / Flow / FlowDraft | 见 §1.6 |
| Orch/Flow 裸称 Run | OrchRun / FlowRun | 跨域必须加前缀 |
| Connector 裸 Binding / S0 `Binding` | ImBinding / BizBinding | 见 §1.8 |
| SyncJob 与 IngestJob 混称 | SyncJob=外部同步；IngestJob=入库 | 分属 Connector / Knowledge |
| 裸 Wiki（知识域） | WikiPage | 表可暂 `kb_wiki` |
| S 文档 `ag_*` / `sk_*`（未落地） | `agent_*` / `skill_*` / `mcp_*` | 以 `@TableName` 为准 |
