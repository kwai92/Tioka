# CS — Tioka 编码规约摘要

> 摘录阿里巴巴 Java 开发手册中与本仓相关的可执行规则，并叠加 Tioka 工程约定。  
> Agent 侧同源约束见 `.cursor/rules/tioka-alibaba-java.mdc`。名词见 [47-GL](47-GL-统一名词释义.md)。  
> 本阶段**不**引入 CheckStyle / P3C 插件；靠评审、ArchUnit 与测试守门。

---

## 1. 命名

- 类名 UpperCamelCase；方法/变量 lowerCamelCase；常量 UPPER_SNAKE_CASE
- 抽象类可用 `Abstract` / `Base` 前缀；异常以 `Exception` 结尾；测试类以 `Test` / `IT` 结尾
- 包名全小写，单数语义域（`com.tioka.system.application.auth`）
- 禁止拼音与英文混用无意义缩写；禁止以下划线开头的成员名（常量除外）

---

## 2. 常量与魔法值（硬）

- **禁止**未经命名的魔法值直接出现在业务逻辑分支、限额、TTL、超时、分页、重试次数中
- 抽为：`private static final`、枚举、或 `@ConfigurationProperties` / 配置项
- 例外：`0`/`1`/`-1` 作为下标或「无」的惯用语义；循环步进 `i++`；测试夹具字面量
- `long` 赋值使用大写 `L`

---

## 3. 方法参数与入参对象（硬）

- 同一方法**业务入参 ≥ 3**（不含 `Principal` / `Page` 等框架上下文）时，必须收敛为 **Command / Query / DTO / record**
- 禁止跨层传递一长串 `String`/`boolean`/`int` 位置参数（易错序、难演进）
- 出参复杂结构同样用 View/DTO，禁止 `Map<String,Object>` 长期冒充契约（调试临时除外）

---

## 4. 持久化与 SQL（硬）

```text
application → infrastructure.Repository → infrastructure.mapper.Mapper
```

- ORM **仅** MyBatis-Plus；**禁止**新增 `JdbcTemplate` / 裸 JDBC 写业务
- **自定义 SQL 必须**放在 `src/main/resources/mapper/**/*.xml`（`classpath*:/mapper/**/*.xml`）
- Mapper **接口**只声明方法签名；**禁止**在接口上使用 `@Select` / `@Insert` / `@Update` / `@Delete`（含 text block）
- 简单 CRUD 优先 `BaseMapper` + `LambdaQueryWrapper` / `ServiceImpl` 能力，勿手写等价 SQL
- Entity 放 `infrastructure.persistence`，继承 `BaseDO` / `WorkspaceAwareDO` / `ImmutableSnapshotDO` / `AppendOnlyDO`
- 行级字段：`createAt` / `updateAt` / `createBy` / `updateBy` / `deleted`；**禁止** `tenantId`
- 主数据禁止物理 `DELETE`（逻辑删）
- `application` **禁止**直接注入 `*Mapper`

---

## 5. 中间件优先（硬）

| 需求 | 优先方案 | 禁止默认自造 |
| --- | --- | --- |
| 分页 | MP `PaginationInnerInterceptor` | 手写 LIMIT 包装到处传 |
| 逻辑删 / 填充 | MP 全局配置 / MetaObjectHandler | 业务里散落 `deleted=false` SQL（XML 内必要过滤除外） |
| 缓存 / 分布式锁 / 冷却 | Spring Data Redis / 现有 `*Cooldown` / Redisson（若已引入） | 本地 `ConcurrentHashMap` 当跨实例真相 |
| 限流 | 现有网关/配额组件 | 业务内自写令牌桶协议（除非 ADR） |
| 消息 | 现有 MQ Topic/Tag 常量 + starter | 业务硬编码 topic 字符串 |
| 事务 | `@Transactional` | 手写 connection 事务边界 |

新增「类中间件」能力必须先查 framework / 已有 starter；无法复用时写 ADR。

---

## 6. 面向对象与相等性

- 覆写 `equals` 必须覆写 `hashCode`
- 比较包装类型用 `equals`；浮点慎用 `==`
- POJO 成员变量 private；访问经 getter/setter（或 record 组件）

---

## 7. 集合与并发

- 判断集合空用 `isEmpty()`
- 线程安全需求明确时使用并发容器或加锁；应用层禁止无必要的 `synchronized`（ArchUnit）

---

## 8. 异常与日志

- 禁止吞掉异常空 `catch`；捕获后须记录或转换后抛出
- 禁止 `System.out` / `System.err` 打业务日志；使用项目 Logger
- 禁止用异常做流程控制

---

## 9. 工程与分层（Tioka）

- `*-biz` **禁止**依赖其他 `*-biz`；只依赖 `*-api` + `tioka-framework` + 中间件 starter

---

## 10. 角色与身份用语

- 平台管理员角色码：`system_admin`（禁止 `tenant_admin`）
- OIDC 组映射配置键：`system-role`（禁止 `tenant-role`）
- 隔离边界：`workspaceId`；新建 API/DO **禁止** `tenantId`
