### DO 基类与时间类型（ADR-029 第 10、20 条修订）

现有 `PersistenceArchTest#tableNameEntitiesMustExtendAgreedBase` 要求每个 `@TableName` 实体继承约定基类，现有基类的时间字段是 `LocalDateTime`。新表沿用这套约定，不引入 `OffsetDateTime`：

| 动作 | 路径 | 说明 |
| --- | --- | --- |
| 新 | `tioka-framework/.../persistence/MutableRecordDO.java` | `createAt`、`updateAt`、`createBy`、`updateBy`，**无逻辑删除**。用于有状态机、需要更新但不软删的表 |
| 新 | `tioka-framework/.../persistence/TechnicalRecordDO.java` | 不含任何审计字段的空基类。只用于下表列出的技术表 |
| 改 | `tioka-server/.../arch/PersistenceArchTest.java` | 允许的基类加入上面两个；新增规则：继承 `TechnicalRecordDO` 的实体只能位于 `TechnicalTables.NAMES` 列出的表 |
| 改 | `tioka-framework/.../persistence/TiokaMetaObjectHandler.java` | `LocalDateTime.now()` 改为 `LocalDateTime.now(ZoneOffset.UTC)` |
| 改 | `application.yml`、`Dockerfile`、CI | JVM `-Duser.timezone=UTC`；JDBC URL 加 `options=-c%20TimeZone=UTC` |

时间规则：DO 字段一律 `LocalDateTime`，**语义为 UTC**（由上面两项保证，`TIMESTAMPTZ` 列读写都按 UTC）；Repository 把 DO 转成领域对象或视图时用 `ldt.toInstant(ZoneOffset.UTC)` 转为 `Instant`，API 只输出 `Instant`。禁止在 DO 中使用 `OffsetDateTime`、`Instant`、`ZonedDateTime`（ArchUnit 规则 `doTimeFieldsAreLocalDateTime`）。

基类选择：

| 基类 | 表 |
| --- | --- |
| `BaseDO` / `WorkspaceAwareDO`（含 `deleted`） | 现有业务表；`im_binding`、`sys_api_key`、`sys_tenant`、`sys_member`、`sys_role` |
| `MutableRecordDO` | `runtime_turn`、`runtime_approval`、`model_turn_freeze`、`gov_quota`、`orch_rule_version` 以外的编排可变表（`orch_work_item`、`orch_run`、`orch_timer`）、`flow_run`、`sys_group`、`sys_resource_acl`、`sys_user_credential`、`im_outbound_ref` |
| `AppendOnlyDO`（`createAt`、`createBy`） | `runtime_item`、`model_usage`（列 `create_by` 已有）、`orch_rule_version`、`sys_user_role`、`sys_external_identity`、`sys_role_permission` |
| `TechnicalRecordDO` | `audit_event`（自带 `ts`）、`sys_outbox`、`sys_consumed`、`sys_dead_letter`、`orch_event`、`orch_decision`、`orch_mandate`、`orch_subscription`、`orch_fact`、`flow_node_run`、`im_conversation_map`、`im_inbound_dedupe`、`sys_group_member`、`runtime_approval_assignee`、`model_default_plan` |

迁移中某表的列与所选基类字段不一致时，以基类为准补列（如 `orch_work_item` 需补 `create_by`、`update_by`），在该表首次落地的 PR 中改契约脚本。

## ENG-10 ArchUnit 守护规则（P0，2 人天）
