## BAS-11 组织与账号同步基线（P1，5 人天）

### 1. 定位与范围

S15 第 10.1 节统一「同步来源 SPI + 能力矩阵 + 适配器」：SPI 是 ADR-026 `OrgDirectoryAdapter` 的正式落点，本项实现该基线（同步引擎 + SPI + 登记与展示 + 差异预演 + 删除保护 + 记录），并由 BAS-12 提供首批适配器。

本项做：来源登记与能力声明；字段映射与转换；全量与增量拉取编排（含分页、限流、重试）；差异预演（dry-run）；删除保护阈值；按「来源 + 外部 ID」幂等合并；本地字段锁定；同步任务与日志；同步接口与事件；适配器插件化装载。本项不做：具体来源的协议实现（BAS-12 飞书 / LDAP、BAS-13 SCIM、F-14 多源）；组织与人员的建模（BAS-02）；账号推送 Keycloak（BAS-03）。

### 2. 同步来源 SPI

SPI 放在 `foundation-starter-sync`（ADR-078 第 1 条），能力面固定为：认证、拉取（全量 / 增量 / 事件回调）、分页与限流、字段映射与转换、外部身份提供、删除保护、幂等键（`来源 + 外部 ID`）。来源实现以插件包提供，同步引擎据此编排；**能力缺失时降级并在同步报告里标注「能力缺失」**，不静默跳过。

```java
package com.tioka.foundation.sync.spi;

/** 同步来源适配器：BAS-11 定义、BAS-12 与 F-14 实现（ADR-078 第 1 条）。 */
public interface SyncSourceAdapter {

    /** 来源标识，与 fdn_sync_source.source_type 一致（FEISHU / LDAP / SCIM / WECOM / DINGTALK …）。 */
    String sourceType();

    /** 能力声明：支持哪些对象、哪种增量方式、是否提供外部身份。引擎据此编排（ADR-078 第 2 条）。 */
    SourceCapabilities capabilities();

    /** 认证：API 凭证 / 应用授权 / OAuth 客户端凭证；凭证复用 ADR-042 的密钥来源，只存引用。 */
    void authenticate(SyncCredentialsRef credentials);

    /** 连通性与能力探测：来源配置保存前调用，返回逐项结果（不抛异常，失败项列出）。 */
    ProbeResult probe();

    /** 全量快照：游标由引擎透传，适配器内部实现分页、限流与退避重试。 */
    Page<ExternalRecord> fetchFull(SyncObjectType objectType, PageCursor cursor);

    /** 增量：按来源声明的增量方式（时间戳 / 变更号 / 事件回调）拉取；无增量能力时返回空页。 */
    Page<ExternalRecord> fetchIncremental(SyncObjectType objectType, IncrementalCursor cursor);

    /** 单对象回查：事件回调或对账修复时按外部 ID 取一条。 */
    Optional<ExternalRecord> fetchOne(SyncObjectType objectType, String externalId);

    /** 增量游标推进点：引擎在增量成功后持久化到 fdn_sync_task.cursor_json。 */
    IncrementalCursor advanceCursor(IncrementalCursor cursor, Page<ExternalRecord> page);

    /** 外部身份提供：按工号 / 已验证邮箱给出候选关联（沿用 ADR-052 第 3 条，不按姓名匹配）。 */
    Optional<ExternalIdentityHint> resolveExternalIdentity(ExternalRecord record);
}

/** 幂等键 = 来源 + 外部 ID（ADR-078 第 1、6 条）。 */
public record SyncKey(String sourceType, String externalId) {}

/** 能力矩阵：同步引擎据此决定生成哪些差异、走哪种增量（ADR-078 第 2 条）。 */
public record SourceCapabilities(
        Set<SyncObjectType> objects,             // ORG_UNIT / PERSON / POSITION / EMPLOYMENT / JOB_GRADE / EXTERNAL_IDENTITY
        Set<IncrementalMode> incrementalModes,   // FULL_ONLY / TIMESTAMP / CHANGE_NUMBER / EVENT_CALLBACK
        boolean providesExternalIdentity,        // 是否提供外部身份
        boolean supportsFieldConversion) {}      // 是否支持字段转换函数

public enum SyncObjectType { ORG_UNIT, PERSON, POSITION, EMPLOYMENT, JOB_GRADE, EXTERNAL_IDENTITY }

public enum IncrementalMode { FULL_ONLY, TIMESTAMP, CHANGE_NUMBER, EVENT_CALLBACK }

/** 字段转换函数扩展点；转换函数名被 fdn_sync_field_mapping.transform 引用。 */
public interface FieldConverter {
    String name();                       // 如 department-code-prefix、date-normalize、enum-normalize
    Object convert(Object rawValue);
}

/** 外部身份候选关联：by 只能是 EMP_NO 或 VERIFIED_EMAIL，不得为 NAME（ADR-026）。 */
public record ExternalIdentityHint(String source, String externalId, MatchBy by, String matchValue) {}

public enum MatchBy { EMP_NO, VERIFIED_EMAIL }
```

**删除保护在引擎侧实现**（§6）：适配器只需在能力声明里说明能否枚举删除（`objects` 是否含被删除对象、是否支持全量快照）。引擎用「本次全量快照 − 上次快照」算出删除 / 停用差异，超过阈值即暂停待确认。

### 3. 能力矩阵（首批实现，F-14 沿用同一张表扩展）

每个来源在适配器里声明「支持哪些对象 + 支持哪种增量方式 + 是否提供外部身份」，与 ADR-078 第 2 条、S15 第 10.1 节一致。

| 来源 | 类型 | 对象 | 增量方式 | 外部身份 | 常见角色 | 交付 |
| --- | --- | --- | --- | --- | --- | --- |
| Foundation 本地 | 本地 | 全部 | 管理台录入 / Excel 导入 | 否 | P0 权威来源（默认） | BAS-02（已交付） |
| 飞书 | IM | 组织、人员、外部身份 | 事件回调 + 定时全量 | 是（open_id / union_id） | 权威来源或外部身份 | BAS-12 |
| LDAP / AD | 目录 | 组织、人员、外部身份 | 时间戳 / 变更号增量 | 是（objectGUID） | 权威来源或外部身份 | BAS-12 |
| SCIM 2.0 | 标准 | 组织、人员 | 推送（服务端） | 是（externalId） | 权威来源或外部身份 | BAS-13 |
| 企业微信 / 钉钉 / 北森 / 泛微 / 金蝶 | IM / HR / OA / ERP | 组织、人员（+岗位、任职、职级） | 事件回调 / 变更号 / 时间戳 | 是 | 权威来源或外部身份 | **F-14**（ADR-078） |

**六源全纳不等于六源并列写主信息**（ADR-078 第 3 条）：一个部署仍只有一个权威来源负责组织树与人员主信息（`fdn_sync_source.authority = TRUE` 的唯一约束），其余来源只补外部身份关联。

### 4. 同步引擎编排

```text
触发（手动 / 定时 / 事件回调）
  → 读来源能力矩阵（SourceCapabilities）与字段映射（fdn_sync_field_mapping）
  → 拉取：全量（fetchFull 分页）或增量（fetchIncremental，游标来自 fdn_sync_task.cursor_json）
  → 差异预演：算 新增 / 修改 / 停用 / 移动，写 fdn_sync_task（status=RUNNING, dry_run 视模式）
  → 删除保护阈值判定（§6）：超阈值 → status=PAUSED、pause_reason=THRESHOLD，等管理员确认
  → 落地：按 SyncKey(来源, 外部ID) 幂等 upsert；被「本地锁定」字段不覆盖（§5）
  → 记录：写 fdn_sync_log 明细、冲突写 fdn_sync_conflict、能力缺失在任务上标注
  → 事件：实际数据变化复用 fdn.org.changed / fdn.person.*；同步结果发 fdn.sync.completed（§10）
  → 台账：每次同步按 ADR-074 写 ext_interaction（§9）
```

- **一个部署只有一个权威来源**（ADR-052 第 4 条）：非权威来源的落地范围被限制为「只写 `fdn_external_identity`」，不碰人员 / 组织主信息；引擎在落地前校验来源角色，越界记为 `AUTHORITY_CONFLICT` 冲突条目。
- **能力矩阵驱动**：来源不支持的对象不生成差异、不落地，只在报告里标注「能力缺失」（`fdn_sync_task.capability_missing = TRUE`）。

### 5. 单一权威来源与本地字段锁定

- **单一权威来源**：`fdn_sync_source.authority` 用部分唯一索引强制「至多一个 TRUE」。切换权威来源是一个显式管理动作（停旧、启新、跑一次全量对账），不做来源间的自动合并。
- **本地字段锁定（档案字段锁定位）**：被标记为「本地锁定」的字段（如手工修正的显示名）不被任何来源覆盖（S15 第 10.2 节、ADR-078 第 5 条）。实现为 `fdn_person.local_locked_fields` 与 `fdn_org_unit.local_locked_fields`（逗号分隔的字段名）；管理台在人员 / 组织单元详情可锁定 / 解锁字段，落地时 `LocalLockResolver` 跳过这些字段，被跳过的字段记为一条 `LOCKED_FIELD` 冲突（可查、不告警）。

### 6. 差异预演（dry-run）与删除保护

- **差异预演**：每次同步先算差异（新增、修改、停用、移动），写 `fdn_sync_task`（`dry_run = TRUE` 时不落地）；管理台可先「预演」再「确认落地」。预演与落地使用同一差异算法，避免口径不一致。
- **删除保护阈值**（S15 第 10.2 节、ADR-052 第 5 条、ADR-078 第 7 条，默认值）：

| 维度 | 默认阈值 | 行为 |
| --- | --- | --- |
| 一次停用人员 | 超过 **5%** 或超过 **50 人** | 暂停落地剩余停用，`status=PAUSED`、`pause_reason=THRESHOLD`，等管理员确认 |
| 删除组织单元 | 超过 **10 个** | 同上（组织单元「删除」实为停用，见 BAS-02 停用前置校验） |

- 新增与修改照常落地，`fdn_sync_task` 标记 `PAUSED`，管理员在工作台逐条确认后继续（`POST /api/sync/tasks/{id}/confirm`）或取消（`/cancel`）。
- 阈值可配（§12）；SCIM 等实时推送来源无法事前预演，改为「时间窗口内累计」判定（BAS-13 §4）。

### 7. 幂等合并

- **幂等键 = 来源 + 外部 ID**（`SyncKey(sourceType, externalId)`）。落地按该键在 `(source, external_id)` 上 upsert，同一批 / 重复批次**零重复新增**。
- 外部为准：权威来源的字段覆盖本地未锁定字段；被锁定字段与外部身份关联不受影响。
- 增量游标：`fetchIncremental` 的 `advanceCursor` 结果写回 `fdn_sync_task.cursor_json`，同一游标重复拉取幂等（`getUpdated` 语义由适配器保证只返回变更集）。
- **每日全量对账**：每日定时跑一次全量快照与差异比对，修复「增量漏拉 / 人为改动」造成的漂移（`mode = RECONCILE`），同样受删除保护阈值约束。

### 8. 表与迁移 SQL 示意（V34〜V37）

```sql
-- V34：同步来源。硬约束：不带 tenant_id（ADR-029 第 60 条）；ULID 主键；TIMESTAMPTZ
CREATE TABLE fdn_sync_source (
    id             VARCHAR(32)  PRIMARY KEY,                       -- src_{ulid}
    code           VARCHAR(64)  NOT NULL,                          -- 来源编码，全局唯一
    name           VARCHAR(128) NOT NULL,
    source_type    VARCHAR(32)  NOT NULL,                          -- FEISHU / LDAP / SCIM / LOCAL / WECOM ...
    authority      BOOLEAN      NOT NULL DEFAULT FALSE,            -- 是否权威来源
    credential_ref VARCHAR(255),                                   -- 凭证引用（ADR-042 密钥来源，只存引用）
    adapter_impl   VARCHAR(255) NOT NULL,                          -- 插件适配器类名
    plugin_sha256  VARCHAR(64),                                    -- 插件包哈希（精简插件宿主校验，FND-12）
    capabilities_json TEXT      NOT NULL DEFAULT '{}',             -- 能力声明缓存（SourceCapabilities）
    config_json    TEXT         NOT NULL DEFAULT '{}',             -- 来源私有配置（不含密钥）
    status         VARCHAR(16)  NOT NULL DEFAULT 'ENABLED',        -- ENABLED / DISABLED
    schedule_cron  VARCHAR(64),                                    -- 定时增量 / 全量对账计划
    create_at TIMESTAMPTZ NOT NULL DEFAULT now(), update_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    create_by VARCHAR(64) NOT NULL DEFAULT 'system', update_by VARCHAR(64) NOT NULL DEFAULT 'system',
    UNIQUE (code));
-- 一个部署只有一个权威来源（ADR-052 第 4 条）
CREATE UNIQUE INDEX uq_sync_source_authority ON fdn_sync_source (authority) WHERE authority = TRUE;

-- V35：字段映射（外部字段 → 内部字段，含默认值与转换）
CREATE TABLE fdn_sync_field_mapping (
    id             VARCHAR(32)  PRIMARY KEY,                       -- map_{ulid}
    source_id      VARCHAR(32)  NOT NULL REFERENCES fdn_sync_source (id),
    object_type    VARCHAR(32)  NOT NULL,                          -- ORG_UNIT / PERSON / POSITION / EMPLOYMENT / JOB_GRADE
    external_field VARCHAR(128) NOT NULL,
    internal_field VARCHAR(128) NOT NULL,                          -- 人员 / 组织 / 岗位字段名
    default_value  VARCHAR(255),
    transform      VARCHAR(64),                                    -- FieldConverter 名称，可空
    required       BOOLEAN      NOT NULL DEFAULT FALSE,
    create_at TIMESTAMPTZ NOT NULL DEFAULT now(), update_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    UNIQUE (source_id, object_type, external_field));

-- V36：同步任务与日志与冲突
CREATE TABLE fdn_sync_task (
    id            VARCHAR(32) PRIMARY KEY,                         -- syn_{ulid}
    source_id     VARCHAR(32) NOT NULL REFERENCES fdn_sync_source (id),
    mode          VARCHAR(16) NOT NULL,                            -- FULL / INCREMENTAL / RECONCILE / PUSH
    trigger_mode  VARCHAR(16) NOT NULL,                            -- MANUAL / SCHEDULED / EVENT
    status        VARCHAR(16) NOT NULL DEFAULT 'RUNNING',          -- RUNNING / PAUSED / SUCCEEDED / FAILED / PARTIAL
    dry_run       BOOLEAN     NOT NULL DEFAULT FALSE,              -- 差异预演不落地
    cursor_json   TEXT,                                            -- 增量游标（时间戳 / 变更号）
    created_count INT NOT NULL DEFAULT 0, updated_count INT NOT NULL DEFAULT 0,
    disabled_count INT NOT NULL DEFAULT 0, moved_count INT NOT NULL DEFAULT 0,
    capability_missing BOOLEAN NOT NULL DEFAULT FALSE,             -- 报告含「能力缺失」标注
    pause_reason  VARCHAR(32),                                     -- THRESHOLD / null
    started_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
    finished_at   TIMESTAMPTZ,
    create_by     VARCHAR(64) NOT NULL DEFAULT 'system');
CREATE INDEX idx_sync_task_source ON fdn_sync_task (source_id, started_at DESC);

CREATE TABLE fdn_sync_log (
    id          VARCHAR(32) PRIMARY KEY,                           -- slg_{ulid}
    task_id     VARCHAR(32) NOT NULL REFERENCES fdn_sync_task (id),
    level       VARCHAR(16) NOT NULL,                              -- INFO / WARN / ERROR
    object_type VARCHAR(32),
    external_id VARCHAR(255),
    action      VARCHAR(16),                                       -- CREATE / UPDATE / DISABLE / MOVE / SKIP / ERROR
    message     TEXT,
    create_at   TIMESTAMPTZ NOT NULL DEFAULT now());               -- 只追加
CREATE INDEX idx_sync_log_task ON fdn_sync_log (task_id, create_at);

CREATE TABLE fdn_sync_conflict (
    id            VARCHAR(32) PRIMARY KEY,                         -- cfl_{ulid}
    task_id       VARCHAR(32) NOT NULL REFERENCES fdn_sync_task (id),
    source_id     VARCHAR(32) NOT NULL REFERENCES fdn_sync_source (id),
    object_type   VARCHAR(32) NOT NULL,
    external_id   VARCHAR(255) NOT NULL,
    conflict_type VARCHAR(32) NOT NULL,                            -- DUPLICATE_KEY / LOCKED_FIELD / AUTHORITY_CONFLICT / IDENTITY_AMBIGUOUS
    detail_json   TEXT,
    resolved      BOOLEAN NOT NULL DEFAULT FALSE,
    resolved_by   VARCHAR(64),
    create_at     TIMESTAMPTZ NOT NULL DEFAULT now());

-- V37：档案字段锁定位（本地锁定字段不被来源覆盖，S15 §10.2、ADR-078 第 5 条）
ALTER TABLE fdn_person   ADD COLUMN local_locked_fields VARCHAR(512) NOT NULL DEFAULT '';
ALTER TABLE fdn_org_unit ADD COLUMN local_locked_fields VARCHAR(512) NOT NULL DEFAULT '';
```

> `fdn_person`、`fdn_org_unit` 由 BAS-02（V1〜V3）建立；本文件的 V37 只新增列，不改其约束。适配器登记沿用 `fdn_sync_source`，不另建表；插件签名 / 版本校验由精简插件宿主（FND-12）负责。

### 9. 出网、凭证与台账

- **凭证**：来源访问凭证（飞书 app_secret、LDAP bind 口令等）通过 `credential_ref` 复用 ADR-042 的密钥来源，只存引用不存值（与 FND-08 的 `CredentialCipher` 一致）。
- **出网**：来源访问统一走出网白名单（FND-07，M4 已落地）；白名单外的目标直接拒绝并按 ADR-072 记审计。
- **台账**：每次同步按 ADR-074 写 `ext_interaction`（方向 OUT，`counterparty` = 来源实例、`endpoint` = 主机 + 路径模板、`operation` = 如 `sync.orgUnit.fetch`、身份模式与 `credential_id`、结果与重试次数）。台账的表名与 `kind` 取值以 ADR-074 为准；若需为目录类来源新增 `kind`，走 ADR-030 变更。

### 10. 接口与事件

**接口**（S15 第 14.1 节「同步」分组：来源配置、手动触发、差异预览与确认、任务记录）。写接口一律要求 `Idempotency-Key`（S15 第 14.1 节、[00-施工总纲](00-施工总纲.md) §2.4），权限码由管理台应用的权限清单声明（BAS-05 导入）。

| 方法与路径 | 权限码 | 说明 |
| --- | --- | --- |
| `GET /api/sync/sources` | `fdn:sync:read` | 来源列表（含能力矩阵与状态） |
| `POST /api/sync/sources` | `fdn:sync:admin` | 新建来源（`Idempotency-Key`） |
| `PUT /api/sync/sources/{id}` | `fdn:sync:admin` | 修改（含权威来源切换、启用 / 停用） |
| `POST /api/sync/sources/{id}/probe` | `fdn:sync:admin` | 连通性与能力探测（逐项结果） |
| `GET/PUT /api/sync/sources/{id}/field-mappings` | `fdn:sync:admin` | 字段映射查询 / 全量替换 |
| `POST /api/sync/sources/{id}/preview` | `fdn:sync:admin` | **差异预演（dry-run）**，返回新增 / 修改 / 停用 / 移动计数与明细 |
| `POST /api/sync/sources/{id}/run` | `fdn:sync:admin` | 手动触发（`mode` = FULL / INCREMENTAL / RECONCILE） |

| `GET /api/sync/tasks/{id}/logs` | `fdn:sync:read` | 同步日志明细 |
| `GET /api/sync/tasks/{id}/download` | `fdn:sync:read` | 下载明细 |
| `GET /api/sync/conflicts?resolved` / `POST /api/sync/conflicts/{id}/resolve` | `fdn:sync:admin` | 冲突查询与处理 |

**事件**（经 outbox 投递到 RocketMQ 主题 `fdn-events`，S15 第 14.2 节；事件体只带 ID、版本与变化类型）：

| 事件 | 触发 | 事件体 | 订阅方 |
| --- | --- | --- | --- |
| `fdn.sync.completed` | 同步（含对账）成功或部分成功 | `{taskId, sourceCode, counts, capabilityMissing}` | 管理台通知、审计 |
| `fdn.sync.paused` | 差异超阈值暂停待确认 | `{taskId, sourceCode, pauseReason, counts}` | 管理台告警 |
| `fdn.sync.failed` | 同步失败 | `{taskId, sourceCode, errorCode}` | 管理台告警 |
| `fdn.org.changed` / `fdn.person.created` / `updated` / `disabled` | 同步实际改动了主数据 | `{id, version, changeType}` | 各应用（由 BAS-02 定义，契约不变） |

> 同步不新增「数据变化」事件模型，只在既有 `fdn.org.changed`、`fdn.person.*` 上增加「来源」取值（ADR-078 第 10 条）。

    delete-protection:

## BAS-12 飞书与 LDAP/AD 同步适配器（P1，5 人天）

本项交付两个内置适配器插件，实现 BAS-11 的 `SyncSourceAdapter` SPI；两者都复用同步引擎的差异预演、删除保护、幂等合并与记录，不各自实现一套。

### 1. 飞书通讯录适配器

| 部分 | 约定 |
| --- | --- |
| 对象 | 部门（含层级与顺序）、用户、职务、部门负责人 |
| 全量 | 调通讯录接口按 `page_token` 分页拉全量；`fetchFull` 内部实现限流与退避重试 |
| 增量 | **事件订阅**（部门 / 用户的创建、更新、删除回调）+ **定时全量兜底**（`IncrementalMode = EVENT_CALLBACK`）；事件到达触发一次定向增量，`fetchOne` 回查单对象 |
| 外部身份 | `open_id`、`union_id` → `fdn_external_identity`（`source = FEISHU_OPEN_ID` / `FEISHU_UNION_ID`），**继承 ADR-026 关联规则**：按工号或已验证邮箱自动关联，或本人用该来源登录确认；**不允许仅凭姓名匹配**（ADR-052 第 3 条、[F-04](F-04-账号与登录与离职联动.md) §2） |
| 部门 → 组织树 | 飞书部门层级映射到 `fdn_org_unit` 树（`parent_id` / `path` / `depth`）；部门负责 → `leader_person_id` |
| 字段映射 | 经 `fdn_sync_field_mapping` 配置（外部字段 → 人员 / 组织字段，含默认值与转换，如部门编码加前缀）；**本地已锁定字段不覆盖** |
| 凭证与出网 | `app_id` / `app_secret` 经 `credential_ref`（ADR-042 密钥来源）；访问走 FND-07 出网白名单、按 ADR-074 写 `ext_interaction` 台账 |
| 限流与重试 | 按接口限速（`foundation.sync.rate-limit.default-qps`）分页节流，命中限流退避重试；重试仍失败记 `fdn_sync_log` ERROR 并告警 |
| 错误与告警 | 凭证失效 / 权限不足 / 限流持续失败 → 任务 `FAILED`、发 `fdn.sync.failed` 并在管理台告警；单条对象失败记日志并跳过，任务记 `PARTIAL` |

### 2. LDAP / AD 适配器

| 部分 | 约定 |
| --- | --- |
| 认证 | **DC 绑定**：bind DN + 口令经 `credential_ref`；可配置多个 base DN 与用户 / 组搜索过滤器 |
| 全量 | 分页搜索（paged results）拉用户与组织（`ou`）；`fetchFull` 实现分页游标 |
| 增量 | 按来源能力声明用**时间戳或变更号**：AD 用 `uSNChanged` / `whenChanged`，OpenLDAP 用 `modifyTimestamp`（`IncrementalMode = CHANGE_NUMBER` 或 `TIMESTAMP`） |
| 外部 ID | **objectGUID 作为外部 ID**（AD；OpenLDAP 用 `entryUUID`）→ `fdn_external_identity`（`source = AD_OBJECTGUID`），二进制作十六进制字符串归一 |
| 组织 DN → 组织树 | `DN` 的 `ou` / `dc` 层级映射到 `fdn_org_unit` 树（`path` / `depth`，树深 ≤ 10 校验）；同名 OU 按 DN 全路径区分 |
| 离职标记 | AD `userAccountControl` 的 `ACCOUNTDISABLE` 位、或用户移出有效 OU → 人员状态置停用 / 离职（`fdn_person.status = DISABLED` / `LEFT`），并按 BAS-14 触发停用离职链路 |
| 字段映射 / 本地锁定 / 出网 / 台账 | 同飞书适配器：经 `fdn_sync_field_mapping` 映射、本地锁定不覆盖、走出网白名单、按 ADR-074 写台账 |
| 限流与重试 | 连接池与请求节流；绑定失败 / 超时退避重试，持续失败告警 |

### 3. 接口、认证与安全

- 两个适配器**不自建 REST**，全部经 BAS-11 的同步接口（`/api/sync/sources` 登记 `source_type`，`probe` 探测，`preview` / `run` 触发）。
- 认证：凭证只存 `credential_ref`，不落库明文；探测与同步都经统一出网通道（FND-07）。
- 安全：不引入 `tenant_id`；台账与日志不记敏感字段（人员手机 / 邮箱按 BAS-02 脱敏规则）；飞书事件回调入口验签（去重前写台账，重复记 `DUPLICATE`，ADR-074 第 2 节）。

## BAS-13 SCIM 2.0 服务端（P2，4 人天）

BAS-13 **取代 FND-09 的实现部分**（[M4-06](M4-06-企业交付与审计.md) §8.1），把 Foundation 从「SCIM 客户端」角色补充为「SCIM 2.0 **服务端**」：由 Keycloak、Entra ID、Okta 等下游 IdP 向 Foundation **推送**组织与人员。P2，可按 [F-00](F-00-F阶段实施计划.md) 第 7 节让路。

### 1. 端点与资源

| 端 | 方法与路径 | 说明 |
| --- | --- | --- |
| 用户 | `GET/POST /scim/v2/Users`、`GET/PUT/PATCH/DELETE /scim/v2/Users/{id}` | SCIM User ↔ `fdn_person`（+ `fdn_account` 联动） |
| 组 | `GET/POST /scim/v2/Groups`、`GET/PUT/PATCH/DELETE /scim/v2/Groups/{id}` | SCIM Group ↔ 有层级的 `fdn_org_unit`（部门作为组） |
| 服务发现 | `GET /scim/v2/ServiceProviderConfig`、`/ResourceTypes`、`/Schemas` | 声明支持的过滤、分页与批量能力 |
| 批量 | `POST /scim/v2/Bulk` | 可选；不支持时在 `ServiceProviderConfig` 声明 `bulk.supported = false` |

### 2. 认证与安全

| 项 | 约定 |
| --- | --- |
| 令牌鉴权 | `Authorization: Bearer <token>`；令牌哈希（SHA-256）存 `fdn_scim_token`，明文只在创建时返回一次；含前缀供识别、`scopes` 限制 Users / Groups 的读写子集、`expires_at` |
| 传输安全 | 仅 HTTPS；503 / 限流返回标准 SCIM `Error` 体 |
| 审计与台账 | 每次推送按 ADR-074 写 `ext_interaction`（方向 IN，`kind = im`/`webhook` 视来源，`dedupe_key` 去重）；写操作记审计 |
| 硬约束 | 不引入 `tenant_id`；ULID 主键；时间 `TIMESTAMPTZ`；`externalId` 作为幂等键（`来源 + 外部 ID`） |

### 3. 过滤、分页与幂等

- **过滤**：支持 RFC 7644 的 `filter` 子集（`eq` / `co` / `sw`，如 `filter=userName eq "zhangsan"`）；不支持时返回 `400` 而非忽略。
- **分页**：`startIndex` / `count`，响应用 `ListResponse{schemas, totalResults, startIndex, itemsPerPage, Resources}`。
- **排序**：`sortBy` / `sortOrder`（仅对白名单属性）。
- **幂等**：`externalId` 作为幂等键（`来源 + 外部 ID`），同一 `externalId` 重复 `POST` 返回 `409`；按 `Idempotency-Key` 与 `dedupe_key` 去重。
- **外部身份**：SCIM `externalId` / `userName` 按工号或已验证邮箱关联 `fdn_person`（`source = SCIM_EXTERNAL_ID`），**不允许仅凭姓名匹配**，关联不上生成待处理关联、不自动建人（[F-04](F-04-账号与登录与离职联动.md) §2）。

### 4. 差异保护（实时推送无预演）

SCIM 是实时推送，无法事前预演（[M4-06](M4-06-企业交付与审计.md) §8.1）：对一个时间窗口（缺省 10 分钟）内**停用累计超过阈值（5% 或 50 人）**的，**暂停执行剩余停用**并等管理员确认；**新增与修改照常**。判定逻辑复用 BAS-11 的 `DeleteProtectionPolicy`，仅把「一次快照」改为「窗口累计」。

### 5. 迁移 V38 与接口

```sql
-- V38：SCIM 服务端令牌（供下游 IdP 推送鉴权）
CREATE TABLE fdn_scim_token (
    id           VARCHAR(32) PRIMARY KEY,                          -- sct_{ulid}
    name         VARCHAR(128) NOT NULL,
    token_hash   VARCHAR(64)  NOT NULL,                            -- SHA-256；明文只显示一次
    prefix       VARCHAR(16)  NOT NULL,                            -- 识别用前缀
    scopes       VARCHAR(255) NOT NULL DEFAULT '',                 -- Users / Groups 读写子集
    status       VARCHAR(16)  NOT NULL DEFAULT 'ENABLED',          -- ENABLED / DISABLED
    last_used_at TIMESTAMPTZ,
    expires_at   TIMESTAMPTZ,
    create_at    TIMESTAMPTZ  NOT NULL DEFAULT now(),
    UNIQUE (prefix));
```

管理面接口（`fdn:sync:admin`）：`GET/POST /api/scim/tokens`、`DELETE /api/scim/tokens/{id}`（明文只返回一次）。

### 6. 测试与完成标准

| 用例 | 层 | 断言 |
| --- | --- | --- |
| `ScimSchemaTest` | 单元 | User / Group → `fdn_person` / `fdn_org_unit` 映射正确；`externalId` 幂等键 |
| `ScimFilterTest` | 单元 | `eq` / `co` / `sw` 过滤解析与不支持时 `400` |
| `ScimServerIT#pushUserAndGroup` | 集成 | 推送 SCIM User / Group 后人员与组织树生效；`externalId` 关联到正确人员，同名不关联 |
| `ScimServerIT#filterAndPagination` | 集成 | `filter` + `startIndex` / `count` 返回正确 `ListResponse` |
| `ScimServerIT#idempotentPush` | 集成 | 同一 `externalId` 重复 `POST` 返回 `409`；`Idempotency-Key` 去重 |
| `ScimServerIT#massDeactivatePause` | 集成 | 10 分钟窗口内停用累计超阈值暂停剩余停用，新增 / 修改照常 |
| `ScimServerIT#tokenScope` | 集成 | 令牌 `scopes` 之外的操作被拒 `403` |

**完成标准**

- [ ] `/scim/v2/Users`、`/scim/v2/Groups` 及服务发现端点可用；Keycloak 或 Entra 推送后组与人员生效
- [ ] 令牌鉴权（SHA-256、明文一次、`scopes`、过期）、过滤分页、`externalId` 幂等全部生效
- [ ] 实时推送的差异保护（窗口累计超阈值暂停）生效；无姓名匹配、无自动建人
- [ ] 每次推送写 `ext_interaction` 台账与审计；无 `tenant_id`
- [ ] §6 用例通过；并入 `GfSyncGateIT`（P2，可让路）；OpenAPI / SCIM 能力声明已更新
