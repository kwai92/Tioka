# 指标与 Trace 清单（GOV-08 / 约束 F20）

M2 起登记；M3 GOV-13 / MH-11 直接读取，**不改名**。自定义 span 属性统一 `tioka.` 前缀。

## 1. 手动 Span 名（GOV-08）

| span 名 | 位置 | 属性 |
| --- | --- | --- |
| `turn.run` | `TurnRunner.run` | `tioka.thread_id`、`tioka.turn_id`、`tioka.origin`、`tioka.agent_version_id` |
| `turn.step` | `AgentLoop` 每步 | `tioka.step` |
| `model.chat` | `DefaultModelGateway.chat` | `gen_ai.system`、`gen_ai.request.model`、`gen_ai.usage.input_tokens`、`gen_ai.usage.output_tokens`、`tioka.failover_count` |
| `tool.invoke` | `DefaultToolGateway.call` | `tioka.tool`、`tioka.tool.ok` |
| `orch.ingest` | `OrchEngineService.ingest` | `tioka.event_type`（ORC-03 实现后补 `tioka.rule_id` / `tioka.run_id`） |
| `orch.dispatch` | `OrchActionDispatcher.dispatch` | `tioka.rule_id`、`tioka.run_id` |
| `messaging.consume` | `IdempotentDeliveryService` | `tioka.messaging.consumer`、`tioka.messaging.event`；父上下文来自信封 `traceparent` |

预留：`tioka.config.version.*`（配置版本，ADR-041）。

## 2. Prometheus 指标（ADR-041 §5.2）

| 指标 | 类型 | 标签 |
| --- | --- | --- |
| `tioka_model_calls_total` | 计数 | provider、binding、alias、purpose、status |
| `tioka_model_errors_total` | 计数 | provider、binding、error_class |
| `tioka_model_latency_seconds` | 直方图 | provider、binding、purpose |
| `tioka_model_ttft_seconds` | 直方图 | provider、binding |
| `tioka_model_tokens_total` | 计数 | provider、binding、direction（in / out / cached） |
| `tioka_model_cost_micros_total` | 计数 | provider、binding |
| `tioka_model_failover_total` | 计数 | from_binding、reason |
| `tioka_model_route_decisions_total` | 计数 | plan、group、decider、outcome |
| `tioka_model_circuit_state` | 仪表 | binding |
| `tioka_quota_usage_ratio` | 仪表 | scope_type、scope_id、metric |
| `tioka_prompt_render_errors_total` | 计数 | template |
| `tioka_config_publish_total` | 计数 | kind、action（publish / rollback / archive） |

基数规则：任何指标都不带用户、会话、Turn 的标签。
