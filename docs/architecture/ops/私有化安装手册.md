# 私有化安装手册（W5-16）

1. JDK 17 + Maven 3.9+
2. `docker compose -f deploy/compose.yml up -d`
3. 配置外置 PG/Redis/MQ 或使用 compose
4. `mvn -pl tioka-server -am spring-boot:run`
5. `cd tioka-ui && npm i && npm run dev`
6. 空气间隙：`tioka.airgap.enabled=true` 并仅配置本地模型
7. 关 mock：`tioka.model.mock=false`（环境变量 `TIOKA_MODEL_MOCK=false`）；配置 Provider 的 OpenAI 兼容 `baseUrl` 与 SecretStore 中的 API Key。可选：`TIOKA_LLM_BASE_URL` + `TIOKA_LLM_API_KEY` 后执行 `bash scripts/smoke-llm-live.sh`
8. SecretStore 遗留 ECB 主密钥（V145 前密文 / 读路径双轨）：`TIOKA_SECRET_MASTER_KEY` / `tioka.secret.master-key`；`prod` 或 `tioka.secret.require-external-key=true` 时缺 key 拒绝启动
9. CredentialCipher 主密钥（FND-08 / Q6）：`TIOKA_CREDENTIAL_MASTER_KEY` / `tioka.credential.master-key`，版本 `TIOKA_CREDENTIAL_KEY_VERSION`（默认 1）。生产由运维生成（建议 `openssl rand -base64 32`），存入密钥库/环境注入，仅运维可轮换；Flyway V145 重加密前必须同时注入旧 `TIOKA_SECRET_MASTER_KEY` 与新 `TIOKA_CREDENTIAL_MASTER_KEY`，失败整体回滚。非 prod 缺省开发密钥会 WARN。
10. 验收：`bash scripts/accept.sh`
