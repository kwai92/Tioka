# 私有化安装手册（W5-16）

1. JDK 17 + Maven 3.9+
2. `docker compose -f deploy/compose.yml up -d`
3. 配置外置 PG/Redis/MQ 或使用 compose
4. `mvn -pl tioka-server -am spring-boot:run`
5. `cd tioka-ui && npm i && npm run dev`
6. 空气间隙：`tioka.airgap.enabled=true` 并仅配置本地模型
7. 关 mock：`tioka.model.mock=false`（环境变量 `TIOKA_MODEL_MOCK=false`）；配置 Provider 的 OpenAI 兼容 `baseUrl` 与 SecretStore 中的 API Key。可选：`TIOKA_LLM_BASE_URL` + `TIOKA_LLM_API_KEY` 后执行 `bash scripts/smoke-llm-live.sh`
8. SecretStore master key：`TIOKA_SECRET_MASTER_KEY` / `tioka.secret.master-key`；`prod` 或 `tioka.secret.require-external-key=true` 时缺 key 拒绝启动
9. 验收：`bash scripts/accept.sh`
