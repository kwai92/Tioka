## 4. P1 处理汇总

各条的具体改法写在对应文档的修订节里，这里只汇总。

### 4.1 安全与合规（18 条）

| 主题 | 处理 |
| --- | --- |
| 经验库来自 TAINTED Turn（EVO-05） | 来源 Turn 为 TAINTED 的条目标 `derivedFromExternal`，不能自动生效；跑 `instruction.detect`，命中就拒绝；只从生产 Turn 提取，排除密封集和 `origin = eval` 的轨迹 |
| `IN` 未出结论前工具已执行 | `IN` 判定期间，工具调用在管线入口等待；结果为 `BLOCK` 时整批丢弃。补 `InBlockBeforeToolExecIT` |
| 外发口不全、影子丢弃两处挂点 | 扩展 M3 已有的 `governance-api` `SinkGuard`，不新建门面。新增「去向类型全集」表，逐类写明走 `SinkGuard` 还是 EgressGuard。影子丢弃只在 `SinkGuard` 做，覆盖 `origin ∈ {shadow, eval}`；TRU-11 去掉三处重复判断。影子 Turn 禁用 `egress != NONE` 的 READ 工具 |
| 沙箱联网绕过标签；准入约束缺失 | 允许联网的沙箱工具缺省标 `injectionSensitive`；出口代理按 Turn 标签判定去向，并写台账；产物继承 Turn 的标签与污点。命名空间启用 PSA `restricted`，加 ValidatingAdmissionPolicy；SA 不给 secrets 权限；节点用 taint 隔离 |
| archiver 权限与保全表 | archiver 改为独立 Job、独立 Secret；DETACH 和 DROP 只能经 SECURITY DEFINER 函数；保全表对 `tioka_app` 只开 INSERT |
| 锚点可重写；时间戳可伪造 | 锚点桶开启 Object Lock（合规模式），写入凭证只给 sealer；SIEM 作为第二锚点必配；`ts` 由触发器强制为 `now()` |
| 身份映射可改；审计含 PII | 身份映射变更写审计并进链；审计 payload 写入时跑 `pii.detect`；ADR-072 增加审计字段白名单 |
| V247/V248 在里程碑中间；回滚丢审计 | 登记为「收权只在里程碑边界」规则的例外，理由是 G4 断言依赖它们；补「恢复后对账流程」：以锚点为准，写 `audit.chain.restored` 并标出丢失区间 |
| 解析引擎处理不可信文件 | LibreOffice 渲染放进无网络 sidecar；PRS-07 中 XXE、大小与解压比、隐藏文字剔除三项前移到 PRS-01 |
| 证照默认走云端 | 证照段缺省用 `PRIVATE` 引擎，用云端需逐空间开启并写审计；增加「敏感个人信息」标记；页图与结果 JSON 继承文档标签，随文档级联删除 |
| 评测裁判绕开去向许可 | 评测调用与生产使用同一套去向许可；找不到合规的不同族裁判时，只出报告、不做门禁。补 `EvalJudgeEgressIT` |
| 观测外送带内容 | GenAI 内容采集缺省关闭；日志脱敏；span 属性和审计外送字段都按白名单。补 `TraceNoContentIT` |
| 放宽类操作单人可做 | 统一规则：放宽类操作需要申请人加安全管理员，申请人不能自审。GOV-06 对 MCP Server、模型 binding、Skill 设平台级「必须审批」下限 |
| SCIM 提权 | Key 限定作用域、来源 IP，可轮换；映射到高权限角色的规则不自动生效；批量角色变更和 DELETE 计入阈值 |
| 前端权限码不一致 | 见第 4.5 节 |
| 离线包签名 | 签名密钥离线保管、双人控制；预置公钥指纹；验签失败就退出；模型只接受 safetensors 或 ONNX；镜像用 cosign 签名，准入时验签；清单加 SBOM 和 CVE 列 |

### 4.5 前端（15 条）

- **权限码：** 以后端登记为准，统一格式为 `模块:资源:动作`。
  - 平台管理员用 `system:admin`，系统模块的细分码统一用 `system:` 前缀，例如 `system:asset:approve`、`system:identity-sync:admin`、`system:sandbox:admin`。
  - 路由入口用 read 码，write 码只用于按钮。
  - 一切操作以后端 403 为准。
  - 补 P3-00d（`tenant:admin` 改名）；旧码兼容到 G3 为止，补 `LegacyAdminCodeRemovedIT`。
- **旧路径：** 补齐旧路径到新路径的对照表，旧路径重定向永久保留；后端拼的前端链接集中到一个常量类管理。
- **页面规则：**
  - 驳回以 M3-04 为准：主因和文字原因至少填一项。
  - 法务页补齐批量处置、进度、快捷键、草稿自动保存、冲突处理、影子期展示规则。
  - DocViewer 在 M3 不显示页码。
  - ONT-08 Web Component 先做一次技术验证 spike。
- **降级：**
  - 「站内通知」改为页内提示加飞书通知。
  - presence 和语义合并移到 M4 之后。
  - i18n 在 M3 只把文案放进资源文件，英文翻译放到 M4 之后。
- **新增要求：**
  - 375px 窄屏下审批台、深链落地页、确认页可用。
  - 五个复杂页面在派给 Cursor 之前先补交互规格。
  - 需负责人确认的页面补四个，每个加 0.5〜1 人天。
- **基础设施：** i18n、ECharts、DOMPurify、Playwright、`useCan` 指令放进新包 P3-00e（2 人天）。

### 4.6 Cursor 可执行性（14 条）

- **专家模板补四件事：**
  - 停下问人的五种情况：设计与包表冲突、依赖还没进 main、没有 DDL 字段表、锁没分配、rebase 时热点文件冲突。
  - 「停下」写成「停下、报告、等待」。
  - 中途申请锁的流程。
  - 特性开关键名统一为 `tioka.<阶段>.<工作项>.enabled`，由骨架包预先登记。
- **PR 规模：** 单包超过 6 人天必须拆成多个 PR，锁只由改共用类的那个小 PR 持有。
- **M4-07 拆包前：**
  - `eval-biz` 按子包划分：`experiment`、`gate`、`judge`、`spec`、`dualrun`、`nightly`、`triage`、`experience`、`selection`。
  - 共用迁移号逐个指定唯一归属（第 3 节 P0-1 已一并处理）。
  - M3 收尾时把条件式 DDL 定死。
  - 跨模块改动逐项列出文件和锁。
- **FE-00 第 10 节：** 展开到第 7 节的粒度，作为 M4 前端包开工的前置，约 3 人天，从前端余量中出。
- **M3-07：** 第 9.5 节有指错的章节，在修订节中列出了正确引用。
