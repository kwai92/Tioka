1. **M3 现在可以继续按第一〜三档推进**，但第三档之后的约 110 个 M3 后端工作项和全部 M3 前端项，还需要一份 M3 并行任务包（与 M2-06 同格式）才能成批派给 Cursor。

3. **F 阶段设计最完整**（S15 有 60KB、细到工作项），缺的只是任务包，放在 M4 收尾时写即可。
4. **前端的「做什么、哪周做」有规划，「页面长什么样」没有设计**，是全局最大的空白（第 5 节）。

### 5.3 缺什么

1. **信息架构与路由总图**：Tioka 四个分区、合同业务系统、Foundation 门户与管理台之间的导航、深链和权限显隐，没有一张总图。
2. **页面规格**：M3 约 25 项、M4 约 31 项、F 约 13 项前端工作项，「设计」列大多只指向 ADR。ADR 定义的是后端字段和状态机，不是页面：列表列、筛选、详情布局、空态、加载、错误、无权限、长任务状态都没写。
3. **Generative UI 组件规范**：S7 列了 interactive_card、form_wizard、approval_card 等 Part 类型，没有逐个组件的规范（字段、交互、Web 与飞书两端的对应）。
4. **视觉规范**：没有设计令牌、配色、间距、图标与文案规范，Element Plus 默认样式之外无约定。
5. **前端任务包与提示词**：M2 有，M3、M4、F 没有。
