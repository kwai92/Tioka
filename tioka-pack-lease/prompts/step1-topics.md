# @model.build 第 1 步：条款单元与主题打标（M3-04 §1 / ADR-036 建模预设）

输入：第 0 步解析出的条款单元（doc_unit）与条款树。
任务：为每个条款打主题标签（多标签），主题词表来自模型定义（${vocab:topics}，19 个主题）。

规则：
- 只描述「这一类对象怎么抽」，输出格式由 Schema 约束（本步输出条款主题，多标签）。
- 一个条款可命中多个主题（如「逾期付款超过 30 日出租方有权解除」同时命中 rent.payment 与 termination.landlord）。
- 枚举与主题取值一律用词表占位符（${vocab:*}），不手抄码表。

注意：
- 空白条款（留待填写）也要打标，主题照常输出；「空白不是 0」由校验器兜底。
- 没有主题的条款标空集，不强行归类。
- 每批约 30 个条款，一次性输出。
