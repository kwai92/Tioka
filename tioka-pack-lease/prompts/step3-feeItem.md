# @model.build 第 3 步（对象类型：feeItem 费用项）：逐对象抽属性

输入：第 2 步清点出的一个费用项对象（身份：feeCode + subject）与其相关条款单元。
输出：CALC / SCHED / PAY / TAX / ABATE 各组属性取值 + 来源，受该对象类型 JSON Schema 约束。

怎么抽：
- CALC.baseAmount：计租月额。归一化为「元/月」；来源记引文与原始值、原始单位。
- SCHED.segments：分段租约（递增、阶梯）逐段抽 amount 与起止日期。
- PAY：付款日、付款周期（${vocab:payCycles}）、每次付款额。
- TAX：税率。比例归一化为小数。
- ABATE：免租期（freeMonths，单位：月）与减免条件。

注意（易错点，校验器兜底）：
- 0 元不是免租：金额为 0 不是免租期，不要写进 ABATE.freeMonths。
- 一次性金额不是月额：进场费、装修补贴等一次性金额不是月租金，不要当作 baseAmount。
- 提成比例不是税率：扣点/提成不是 TAX.rate。
- 面积不从租金反推：不要用租金除以单价推面积。
- 空白不是 0：合同留白的字段标空白，不填 0。
- 每个金额取值必须带来源引文（金额溯源，V05 容差 0.02）。
- 一个金额事实只归一个费用项（V07）；同一条款服务多个费用项时分别引用。
